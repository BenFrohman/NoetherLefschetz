A monodromy group belongs to a family, not to one smooth fibre. This file records the numbers that the locked sextic determines, and it refuses a fake generating set.

## Ranks

For a smooth sextic fourfold in \(\mathbb{P}^5\),

\[
(h^{4,0},h^{3,1},h^{2,2},h^{1,3},h^{0,4})=(1,426,1752,426,1),
\qquad b_4=2606.
\]

The hyperplane class spans the monodromy invariants of the universal family, so the primitive lattice has rank \(2605\). The intersection form on \(H^4\) is symmetric. The monodromy lands in an orthogonal group, not a symplectic group. The form \(\Omega_0\) of type \((1,6)\) in `BenFrohman/OmegaZero34` is a different local system.

## One loop, as a theorem, not a matrix

A loop around an ordinary node acts by a Picard--Lefschetz reflection in the vanishing cycle \(\delta\). The middle degree is even, so \(\delta\) has nonzero square and the transformation is a reflection. Beauville's theorem says that, for the universal family of smooth hypersurfaces, the group generated by those reflections is Zariski-dense in the orthogonal group of the vanishing cohomology.

That is a theorem in the literature. It is not a calculation of matrices in this repository. No file here contains a generating set of \(O(H^4_{\mathrm{prim}})\).

Deligne's invariant-cycle theorem then gives, for a very general sextic,

\[
H^4(X,\mathbb{Q})^{\mathrm{Mon}}=\mathbb{Q}\,h^2,
\qquad
H^4(X,\mathbb{Q})\cap H^{2,2}(X)=\mathbb{Q}\,h^2.
\]

## The lattice that was computed

On \(V(F)\), with \(\Pi=V(x_3,x_4,x_5)\) and \([S]=h^2-[\Pi]\), the normal sequence

\[
0\to N_{\Pi/X}\to \mathcal{O}(1)^{\oplus 3}\to \mathcal{O}(6)\to 0
\]

is exact, because \((x_0^5,x_1^5,x_2^5)\) has no common zero on \(\Pi\). Chern classes give \(c(N)=1-3h+21h^2\), so

\[
[\Pi]\cdot[\Pi]=\int_\Pi c_2(N)=21.
\]

Together with \(h^4=6\) and \(h^2\cdot[\Pi]=1\),

\[
\begin{pmatrix}
\langle h^2,h^2\rangle & \langle h^2,[\Pi]\rangle\\
\langle[\Pi],h^2\rangle & \langle[\Pi],[\Pi]\rangle
\end{pmatrix}
=
\begin{pmatrix}6&1\\1&21\end{pmatrix},
\qquad
\det=125=5^3.
\]

The residual pairings are the expansion of \([S]=h^2-[\Pi]\):

| pairing | value |
|---|---|
| \(h^2\cdot[S]\) | \(5\) |
| \([\Pi]\cdot[S]\) | \(-20\) |
| \([S]\cdot[S]\) | \(25\) |

The integral primitive class is \(\beta=h^2-6[\Pi]=[S]-5[\Pi]\).

| pairing | value |
|---|---|
| \(\beta\cdot h^2\) | \(0\) |
| \(\beta\cdot[\Pi]\) | \(-125\) |
| \(\beta\cdot[S]\) | \(125\) |
| \(\beta\cdot\beta\) | \(750\) |

So \(\beta\) lies in \((h^2)^\perp\). It is an algebraic class in the primitive lattice. It is not a vanishing cycle, and it is not a miss.

Discriminant \(125\) does not decide whether \(\mathbb{Z}h^2+\mathbb{Z}[\Pi]\) is saturated in \(H^4(X,\mathbb{Z})\). An unsaturated class would still lie in \(\mathbb{Q}\langle h^2,[\Pi]\rangle\), hence would be algebraic over \(\mathbb{Q}\).

## Two groups, two invariant ranks

| group | known invariant subspace | rank |
|---|---|---|
| \(\mathrm{Mon}\) of all smooth sextics | \(\mathbb{Q}h^2\) | \(1\) |
| \(\mathrm{Mon}_\Pi\), sextics containing a plane | contains \(\mathbb{Q}h^2+\mathbb{Q}[\Pi]\) | at least \(2\) |

\(\mathrm{Mon}_\Pi\) is the image of the fundamental group of that smaller base. It can fix \(\beta\) while the full group does not. The index of \(\mathrm{Mon}_\Pi\) in the orthogonal group, and a matrix model of either group on the rank-\(2605\) lattice, are not computed.

## Not this calculation

The Milnor monodromy of the plane-curve germ \(W=u^5v+v^6\) is an operator on a lattice of rank \(25\), with characteristic polynomial \((t^6-1)^4(t-1)\). That operator is local singularity data. It is not a subgroup of \(O(H^4_{\mathrm{prim}}(V(F)))\).
